# 《金融沙盘 01：守住泰铢》 v1 构建规格

> 一条诚实涌现缝的最小沙盘。不是完整经济模拟器。
> 唯一动态因果链：储户群体状态 → 短期外债/储备比值 → 央行可行动空间。
> 唯一玩家输入：储户阶段一次选择。其余由历史基线决定，零随机。

---

## 1. 文件与路由

- 目录：`financial-sandbox/`（独立子系列，不进 articles/ 的 reader iframe 流）。
- 主文件：`financial-sandbox/baht.html`（自包含单文件 HTML+CSS+JS，无构建，参照 chapbook 自包含习惯）。

## 3. 状态模型（全部确定性，零随机）

```js
state = {
  scene: 1,                // 1储户 / 2索罗斯×A股 / 3央行 / 4结算
  saverChoice: null,       // 'hold' | 'partial' | 'all'  ← 唯一玩家输入
  cbChoice: null,          // 'defend' | 'rates' | 'float' | 'controls'
}

// 历史基线（外生，玩家不可改，写死）
const HIST = {
  debtToReserve: 1.12,     // 1997 短期外债/储备 >1（历史事实，跨过阈值）
  reservesBar: 0.62,       // 相对储备条 0–1，纯视觉示意，不参与判定
  crowdFlight: 'heavy',    // 历史人群撤离：重
};
// 玩家选择的可见 delta（小，且非决定性）
const DELTA = {
  hold:    { ratio: -0.02 },
  partial: { ratio:  0.00 },
  all:     { ratio: +0.02 },
};
finalRatio = HIST.debtToReserve + DELTA[state.saverChoice].ratio; // 始终 ≥1.10
thresholdCrossed = finalRatio >= 1;  // 历史复现下恒为 true
```

**诚实约束**：
- `thresholdCrossed` 在历史复现里恒为 true。玩家 delta 可见，但不改变"跨阈值"这件事。
- 不存在"玩家靠 hold 让比值 <1"的路径——一个人持汇不能扭转国家比值。这是论点要求。
- 储备相对条仅视觉示意；**唯一判定量是短期外债/储备比值与阈值 1**。不出现伪造的精确美元断点。

## 4. 唯一阈值

- 指标：**短期外债 / 外汇储备**。
- 阈值：**= 1**（Greenspan-Guidotti 规则；<1 可守，≥1 难守）。
- 历史锚点：1997 年泰国该比值 >1（短期外债规模超过储备）——真实的"守不住"信号。
- 展示：阈值标尺，红点落 ≥1 一侧，标注"承诺已难以无限兑现"。
- 分叉：阈值 crossed 时四张政策卡"性质"改变（见 §6）。选项不灰掉——历史复现里它本就被跨过。

## 5. 场景流（约 7 分钟）

### 场景 1 · 储户（约 2 分钟）
- 档案条："1997 年 6 月 · 曼谷"。
- 正文：邻居换美元、银行排队、新闻仍说稳定。
- 互动：你持有 10 万泰铢存款。三选一：持有全部 / 换出一部分 / 全部换出。
- 反馈（克制）：**只**显示你的账户变动（泰铢/美元数字）。不解释、不归因、不给因果。让"5 万泰铢"成为留在记忆里的具体物件。
- 群体状态：展示**外生市场信号**（排队增加、海外资金撤离、新闻强调稳定）——是你观察到的信号，不是你造成的。生成 `crowdFlight = 'heavy'`（写死，历史）。
- **禁止**显示"因为你换了，所以大家也换了"。

### 场景 2 · 索罗斯 × A股（约 1.5 分钟）
- 双屏：
  - 左"1997 · 泰铢"：泰国承诺 1美元≈25泰铢（一条具体价格承诺）；市场在猜"泰国还能不能兑现 25"。
  - 右"A股 · 某次行情"：无人承诺价格；情绪上涨→追涨→强化 / 下跌→卖出→恐慌。
- 中间落句：
  > 选美，是两边共同的人性。
  > 承诺，是决定一边会不会变成危机的结构。
  > 二阶信念不会自动制造危机。它需要撞上一条无法无限兑现的承诺。
- 补一刀（不全说死）：
  > 泰铢的断点，是一条公开承诺。
  > A股的断点，藏在杠杆、流动性和交易规则里。
  > 人性相似，但系统决定了恐慌在哪里聚集。
- 互动（A股选美）：你看到一只股票涨 8%。三选一：买入/观望/卖出。下一屏给**静态**人群比例（如 62/23/15，明确标注"示意，非实时"），不伪装实时。再问"你还坚持吗"——**不判"改了=对"**，把"你的推理有没有变"作为观察对象，不是规定结果。
- 此场景为预设叙事 + 一个轻互动；不携带玩家动作进入央行（设计如此）。

### 场景 3 · 央行（约 2.5 分钟）
- 入场：先不递菜单。先展示"当前局面"：
  - 外汇储备：相对条（0.62 ± delta 视觉），注"持续下降"。
  - 储户兑换压力：重（外生）。
  - 海外资本撤离：高。
  - 固定汇率可信度：下降。
  - **阈值标尺**：短期外债/储备 = 1.12（+你的 delta），红点 ≥1 一侧，标注"已跨过守得住的界线"。
  - 储户压力条上标小刻度"你的选择在此"——可见，但条的主体由外生人群决定（诚实可视化）。
- 四张政策卡（单选，"你优先保护什么"）：
  1. 守住汇率 → 动用外汇储备
  2. 守住货币吸引力 → 提高利率
  3. 守住外汇储备 → 放弃固定汇率
  4. 守住资金边界 → 资本管制
- 每张卡正面两栏：**保护** / **牺牲**（牺牲写明，不留到结算）。
- 阈值 crossed 下卡的"性质"标注（不灰掉）：
  - ① 动用储备：可执行，但"只能延缓失守，无法恢复信心"。
  - ② 提高利率：可执行，但"实体经济承压已高"。
  - ③ 放弃固定汇率：可执行。
  - ④ 资本管制：可执行，但"政策信用将受损"。
- 玩家单选 → 进入结算。

### 场景 4 · 结算（约 1 分钟）
- B 型账单：不设总分、不评最优、不胜负、不排行。
- 结构：
  - "你进入央行时"：重述局面（系统已被推到边缘）。
  - "你选择：X" → 代价转移图（见 §6）。
  - 历史对照：1997 年 7 月 2 日泰国放弃固定汇率（= 选项③的历史路径）。展示"历史把代价留给了谁"。
  - 落句："你和历史没走同一条路。但你们都无法让代价消失。"
- 收尾核心句（caption，不承担解释，字号小、置底）：
  > 你刚才做的，和这里的无数人一样。
  > 危机很少由一个人的错误造成。
  > 它由无数个对个人而言合理的选择，共同造成。

### 结尾 · 反事实揭示面板（场景 4 末尾，关键）
两段，把"涌现缝"从隐形变可见：
1. **个体诚实**：
   > 你换出的那笔，在国家尺度上几乎不可见。
   > 1997 年的泰国，短期外债已经超过外汇储备——无论你换不换，这条线都被跨过了。
2. **系统反事实**（亮出玩家没走的岔路，单次通关即可见，无需重玩）：
   > 但如果储户群体没有集中撤离，央行本还有更多时间。
   > 动用储备，本可以再延缓一段——
   > 只是短期外债仍在那里。危机会被推迟，不会消失。

这一板兑现"沙盘"承诺：玩家看见自己那笔汇入了让"守住"变得不可行的系统状态，但既不是原因，也无无痛选项。

## 6. 四张代价转移图（阈值 crossed 变体，历史复现下唯一可玩形态）

每张：保护了谁 / 谁替这个决定付了账 / 历史注。

### ① 动用外汇储备（守住汇率）
- 保护：固定汇率（短期）、持有泰铢资产的人
- 付账：外汇储备（持续消耗）、未来政策空间、最终被迫调整时的冲击更陡
- 性质（crossed）：储备已不足持续干预 → 只能延缓失守
- 历史注：泰国耗资干预数月后仍被迫放开；越晚放开，冲击越大。

### ② 提高利率（守住货币吸引力）
- 保护：短期抑制投机、汇率（短期）
- 付账：企业融资成本、房地产、实体经济
- 性质（crossed）：实体已脆弱 → 高利率进一步加压
- 历史注：泰国曾大幅提高利率；高利率本身加剧了本已脆弱的企业与金融体系压力。

### ③ 放弃固定汇率（守住外汇储备）
- 保护：外汇储备（停止消耗）、避免储备耗尽后的更坏局面
- 付账：持有美元债务的企业（偿债暴涨）、持有泰铢资产的人（购买力下降）、短期市场信心
- 性质（crossed）：停止消耗，但汇率将大幅调整
- 历史注：这正是泰国 1997 年 7 月 2 日所做的。浮动后泰铢大幅贬值。
- （若玩家选③：提示"你走的，正是历史的路径"。）

### ④ 资本管制（守住资金边界）
- 保护：减缓资金外流、短期止血
- 付账：国际资本信任、跨境融资能力、长期政策信誉
- 性质（crossed）：可减缓，但信任成本高
- 历史注：泰国当时未主要采用；马来西亚后来采用，争议至今。

历史对照面板（所有选项共用）：
> 1997 年 7 月 2 日，泰国放弃固定汇率。
> 历史把代价主要留给了：持有美元债务的企业、持有泰铢资产的人、金融体系与实体经济。
> 历史没有找到无痛选项。你也没有——但你让代价落在了不同的人身上。

## 7. 诚实性护栏（实现期不可违反）

1. 储户选择永远不决定人群状态；人群是外生历史。玩家 delta 可见、小、非决定性。
2. 阈值（短期外债/储备=1）在历史复现里恒被跨过；不存在"玩家独自逆转"路径。
3. 四张代价图均以史实为依据；不出现 +2/-1 魔法系数；不出现伪造的精确美元断点。
4. A股人群比例为静态示意，明确标注，不伪装实时聚合。
5. 结算不设总分/胜负/排行；只揭示"代价落在了谁身上"。
6. 结算的低位储备状态归因于"人群/所有人"，永不归因于"你的储户选择"。
7. 收尾"你也没有[无痛选项]"不抹掉玩家真实的分配差异。
8. 零随机。

## 8. 构建架构

- 单文件 `baht.html`：HTML 骨架 + 内联 `<style>` + 内联 `<script>`。
- JS：极小状态机。`state` 对象 + 四个 `renderSceneN()` + `go(n)` 转场。无框架、无依赖。
- 转场：淡入/纸页感，克制（参考 chapbook），避免花哨动画。
- 可访问性：选择用 `<button>`，状态用文字标注（不仅靠颜色/红点）。
- 移动端：参考 chapbook 收敛规则。

## 9. v1 不做（明确边界）

六轮、动态索罗斯 AI、政策组合、四人格独白、独立 A股番外、反事实模式、实时聚合、随机人群——全部不做。

v2 接口：结尾反事实面板是"完整反事实沙盘"的天然起点；把单一阈值扩展为状态图即可。
